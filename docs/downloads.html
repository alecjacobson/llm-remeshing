Download the models

All 100 Blender scenes and the source/result mesh arrays are stored with Git LFS. Use each gallery card for an individual Blender download, or fetch all scenes:

git lfs install
GIT_LFS_SKIP_SMUDGE=1 git clone https://github.com/alecjacobson/llm-remeshing.git
cd llm-remeshing
git lfs pull --include="results/*/*.blend"

To also download the original mesh arrays, quad arrays, and repair intermediates:

git lfs pull

GitHub’s ordinary source ZIP may contain LFS pointers instead of the binary assets; cloning with Git LFS retrieves the actual files. The full Blender collection is approximately 2.6 GB. All models retain their individual source licenses.
